项目源码

电商智能分析平台 · Java + Vue 实现

以下为该项目的核心源代码，涵盖后端 Spring Boot 服务（Text2SQL、认证、统一响应）与前端 Vue 路由守卫。

统一响应体 Result.java
// 统一 API 响应结构，泛型支持任意数据类型 public class Result<T> { private int code; private String message; private T data; public static <T> Result<T> success(T data) { Result<T> r = new Result<>(); r.code = 200; r.message = "OK"; r.data = data; return r; } public static <T> Result<T> error(String msg) { Result<T> r = new Result<>(); r.code = 500; r.message = msg; return r; } }
认证服务（登录 / 注册） AuthService.java
// 使用 BCrypt 加密密码，返回简化 token @Service @RequiredArgsConstructor public class AuthService { private final UserMapper userMapper; private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder(); public String login(String username, String password) { User user = userMapper.selectOne( new LambdaQueryWrapper<User>().eq(User::getUsername, username)); if (user == null || !passwordEncoder.matches(password, user.getPassword())) throw new RuntimeException("用户名或密码错误"); return UUID.randomUUID().toString(); // 简化 token } public User register(String username, String password, String email) { // 检查用户名唯一性 if (userMapper.selectCount( new LambdaQueryWrapper<User>().eq(User::getUsername, username)) > 0) throw new RuntimeException("用户名已存在"); User user = new User(); user.setUsername(username); user.setPassword(passwordEncoder.encode(password)); user.setEmail(email); user.setRole("user"); userMapper.insert(user); return user; } }
Text2SQL 生成服务 SqlGenService.java
// 提示词模板 + 调用 DeepSeek 生成 SQL @Service @RequiredArgsConstructor public class SqlGenService { private final OpenAiChatModel chatModel; private static final String PROMPT = """ 你是一个SQL专家。根据以下数据库表结构： - customers(id, age, gender, location, subscription_status, purchase_frequency, previous_purchases) - products(id, item_name, category, size, color, season) - orders(id, customer_id, product_id, purchase_amount, payment_method, discount_applied, rating, review_rating, shipping_type) 将用户的自然语言查询转换为一条只读SQL语句。 要求： 1. 仅生成SELECT语句，不要有任何修改数据库的操作。 2. 不要使用分号结尾，不要加注释。 3. 查询商品信息时，必须包含 products.id 和 products.item_name。 4. 如果问题无法转换为SQL，返回"无法理解"。 用户问题：%s SQL："""; public String generateSql(String question) { return chatModel.generate(String.format(PROMPT, question)).trim(); } }
自然查询接口 NaturalQueryController.java
// 接收自然语言 → 生成 SQL → 安全校验 → 执行并返回 @RestController @RequestMapping("/api/query") @RequiredArgsConstructor public class NaturalQueryController { private final SqlGenService sqlGenService; private final JdbcTemplate jdbcTemplate; @PostMapping("/natural") public Result<?> query(@RequestBody Map<String, String> body) { String question = body.get("question"); String sql = sqlGenService.generateSql(question); if (!sql.trim().toUpperCase().startsWith("SELECT")) return Result.error("生成的SQL不安全或无法理解"); try { List<Map<String, Object>> rows = jdbcTemplate.queryForList(sql); return Result.success(rows); } catch (Exception e) { return Result.error("查询执行失败: " + e.getMessage()); } } }
Vue 路由守卫 router/index.js
// 未登录跳转登录页，已登录跳转商品页 router.beforeEach((to, from, next) => { const token = localStorage.getItem('token'); if (!token && !to.meta.noAuth) { next('/login'); } else if (token && to.path === '/login') { next('/products'); } else { next(); } });
补充说明
  • 统一响应体：所有 API 返回 Result<T> 结构，包含 code、message、data，前端通过拦截器统一处理。
  • 密码加密：使用 BCryptPasswordEncoder 存储哈希密码，保障安全性。
  • 提示词工程：通过明确表结构、安全约束（仅 SELECT）和输出格式，有效提升 SQL 生成准确率。
  • 安全执行：后端强制校验 SQL 以 SELECT 开头，拒绝任何 DML/DDL 操作，防止数据篡改。
  • 路由守卫：基于 localStorage 的 token 进行鉴权，未登录用户自动重定向至登录页。
  • 扩展性：可进一步接入 Redis 缓存、多数据源支持等，提升性能与可用性。
