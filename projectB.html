基于YOLO与PaddleOCR的板坯号识别系统

目标检测 · 光学字符识别 · 工业场景应用
YOLO PaddleOCR OpenCV PyTorch Python CUDA
项目概述

本方案面向钢铁行业中板坯号自动识别的需求，基于 YOLOv11n 目标检测算法与 PaddleOCR 文字识别技术，构建了一套端到端的板坯号自动识别系统。系统首先通过 YOLO 模型在视频帧中定位板坯正面区域，提取该区域图像后交由 PaddleOCR 进行文字识别，输出板坯号信息。该系统可替代人工抄录，提升产线数据采集的自动化水平。

关键技术介绍
1. YOLO（You Only Look Once）

YOLO 是一种基于深度学习的端到端实时目标检测算法，由 Joseph Redmon 等人于 2016 年首次提出。其核心思想是将目标检测任务视为一个统一的回归问题，通过单个神经网络直接从输入图像中预测边界框的坐标和类别概率。与传统的两阶段检测算法（如 R-CNN 系列）不同，YOLO 采用单阶段检测策略，将图像划分为 S×S 的网格，每个网格负责预测中心点落入该网格的目标。这种设计使得 YOLO 在保持较高检测精度的同时，具备极快的推理速度。本系统采用 Ultralytics 团队开源的 YOLOv11n 作为板坯区域检测的基础模型，经过两轮迭代训练后，可准确定位视频画面中的板坯正面区域。

图1：YOLO 模型检测板坯正面区域示意图
2. PaddleOCR（Paddle Optical Character Recognition）

PaddleOCR 是百度飞桨（PaddlePaddle）开源的中文 OCR 工具库，集成了文本检测、方向分类和文字识别三大核心模块。其识别引擎基于 CRNN（卷积循环神经网络）与 CTC（连接时序分类）损失函数，支持中英文及多种语言的高精度文字识别。PaddleOCR 提供了丰富的预训练模型，可灵活部署于 CPU 或 GPU 环境。本系统使用 PaddleOCR 的轻量级英文识别模型，在 CPU 环境下运行，对板坯号中常见的数字与字母组合进行识别，满足产线实时性要求。

图2：PaddleOCR 简介
3. OpenCV（Open Source Computer Vision Library）

OpenCV 是一个开源的计算机视觉库，提供了丰富的图像处理和视频分析功能。本系统利用 OpenCV 进行视频流的读取与帧提取、YOLO 检测结果的图像裁剪与预处理，以及检测界面的实时显示与交互控制（如暂停、快进、慢放等）。OpenCV 的高效图像处理能力为系统的实时运行提供了基础保障。

图3：OpenCV 简介
核心问题与解决方案

初方案设计：基于 YOLOv11n 识别板坯正面区域，利用 OpenCV 裁剪出板坯区域图像，交由 PaddleOCR（CPU 环境 + 英文识别模型）进行文字识别。初步评估认为板坯号主要由数字和字母构成，识别难度较低。

主要挑战：在实际测试中，系统面临以下问题：

  • 反光干扰：金属板坯表面存在强反射，部分区域的字符因反光而难以辨认，导致 OCR 识别准确率下降。
  • 规格不统一：不同批次板坯的号牌规格、字体大小、印刷位置存在差异，增加了文字识别的难度。
  • 定位与识别矛盾：YOLO 对板坯区域的定位较为准确，但裁剪后的图像质量受光照、角度等因素影响，PaddleOCR 的文字识别准确率不理想。

优化方案：

  • 双 GPU 并行推理：在两个不同的计算环境中部署 YOLO（GPU）与 PaddleOCR（GPU），利用双 GPU 分别承担目标检测与文字识别任务，充分发挥 GPU 的并行计算优势，提高整体识别准确率。
  • 模型微调：针对板坯号的字体与分布特征，对 PaddleOCR 的识别模型进行针对性微调训练，提升特定场景下的识别精度。
  • 图像预处理增强：在将裁剪区域送入 OCR 之前，增加自适应直方图均衡化、去噪等预处理步骤，减轻反光与光照不均的影响。

注：双 GPU 方案在提升识别准确率的同时，可能引入一定的速度损耗。实际部署中需根据产线节拍要求，在准确率与实时性之间进行权衡。

技术实现流程
  1. 数据采集与标注：采集产线现场板坯视频数据，使用 LabelImg 工具对板坯正面区域进行边界框标注，构建目标检测训练数据集。
  2. 模型训练：基于 YOLOv11n 通用检测模型进行迁移学习，经两轮迭代训练后，模型对板坯区域的定位精度达到部署要求。
  3. 视频流读取：使用 OpenCV 读取产线监控视频文件或实时视频流，逐帧提取图像。
  4. 板坯区域检测与裁剪：YOLO 模型对每一帧图像进行推理，输出板坯区域的边界框坐标，根据坐标裁剪出板坯区域子图。
  5. 文字识别：将裁剪后的板坯区域图像送入 PaddleOCR 模型，执行文字检测与识别，输出板坯号文本。
  6. 结果可视化：在原视频帧上绘制检测框并叠加识别文本，支持交互式播放控制（暂停、快进、慢放等），便于人工校验。
核心代码

以下为核心视频处理与 YOLO 推理代码：

# 导入依赖库 import cv2 from ultralytics import YOLO # 加载 YOLO 板坯检测模型 model = YOLO("Blockbest.pt") # 打开视频文件 video_path = r"C:\...\C6看板号.avi" cap = cv2.VideoCapture(video_path) # 获取视频参数 fps = int(cap.get(cv2.CAP_PROP_FPS)) total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT)) # 交互控制参数 pause = False skip_frames = 1 # 快进倍数 current_frame = 0 # 当前播放帧索引 while True: if not pause: # 逐帧读取并推理 ret, frame = cap.read() if not ret: break results = model(frame, conf=0.5) annotated_frame = results[0].plot() # 叠加帧信息 cv2.putText(annotated_frame, f"Frame: {current_frame}/{total_frames}", (10, 30), cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2) cv2.imshow("YOLO Detection", annotated_frame) # 键盘交互控制 key = cv2.waitKey(1) & 0xFF if key == ord('q') or key == 27: # 退出 break elif key == 32: # 空格：暂停/继续 pause = not pause elif key == ord('f'): # 快进 skip_frames = min(skip_frames * 2, 16) elif key == ord('s'): # 慢放 skip_frames = max(skip_frames // 2, 1)

技术栈
  • 目标检测框架：Ultralytics YOLOv11n
  • 文字识别框架：PaddleOCR
  • 图像处理：OpenCV (cv2)
  • 深度学习后端：PyTorch / PaddlePaddle
  • 计算加速：CUDA / cuDNN（GPU 推理）
  • 开发环境：Python 3.10
  • 部署方案：单 GPU（检测）/ 双 GPU（检测 + 识别）
