电商智能分析平台

基于LangChain4j实现的低门槛，高效率自然语言驱动的智能数据分析平台。
Vue 3 Spring Boot LangChain4j DeepSeek MySQL Text2SQL
项目概述

在电商行业竞争日益激烈的背景下，海量商品数据的管理与深度分析已成为平台运营的核心竞争力。传统电商后台管理系统依赖固定报表模板和预设筛选条件，运营人员需掌握复杂 SQL 语句才能获取个性化数据，技术门槛高且效率低下。

本课题以 Kaggle 公开数据集 "Customer Shopping Behavior Dataset" 为基础，融合大语言模型技术，构建了一个支持自然语言交互的电商智能分析平台。通过 Text2SQL 智能查询与 AI 分析报告 两大核心能力，使非技术人员也能通过自然语言快速完成数据查询与业务洞察，有效降低数据分析门槛，提升决策效率。

技术架构

系统采用前后端分离架构，后端基于 Spring Boot + MyBatis-Plus，前端采用 Vue 3 + Element Plus，AI 能力通过 LangChain4j 框架接入 DeepSeek 大模型。

1. Spring Boot 3.x

通过自动配置和约定优于配置的理念，大幅减少 XML 配置和样板代码。内置嵌入式 Tomcat 服务器支持一键启动，在类型安全、企业级事务管理和生态成熟度方面具有显著优势。

2. Vue 3 + Element Plus

Vue 3 采用 Composition API 和 Proxy-based 响应式系统，逻辑复用更灵活，TypeScript 支持完善。Element Plus 提供了丰富的表单、表格、对话框等组件，支持按需引入，有效控制打包体积。

3. LangChain4j + DeepSeek

LangChain4j 是 Java 生态中成熟的大模型应用开发框架，通过 AiServices 和 @Tool 注解可快速构建具备工具调用能力的智能 Agent。DeepSeek 提供高性能、低成本的推理服务，支撑 Text2SQL 与智能报告生成。

4. MySQL 规范化存储

将原始 CSV 宽表规范化为 customers、products、orders 三张关系表，消除数据冗余，通过外键关联保证参照完整性，为高效查询与数据一致性奠定基础。

核心功能模块
登录页 (/login)
用户名密码登录，表单校验，路由守卫自动拦截未认证访问。
商品浏览 (/products)
卡片网格展示商品，支持名称/分类实时搜索，分页加载。
购物车 (/cart)
localStorage 持久化，修改数量、移除商品、提交订单。
商品管理 (/admin)
增删改查 + 自然语言智能搜索，动态渲染查询结果表格。
数据查询与分析 (/query)
自然语言输入 → Text2SQL 转换 → 动态表格展示。内置示例查询标签（"红色商品"、"夏季服装"、"高价订单"），零门槛上手。
技术实现流程
  1. 数据规范化：使用 OpenCSV 动态解析原始数据集，将单张宽表拆分为 customers、products、orders 三张关系表，消除冗余并建立外键关联。
  2. 后端分层架构：Controller → Service → Mapper 三层结构，统一响应体 Result<T>，全局异常处理，依赖注入管理对象生命周期。
  3. Text2SQL 智能查询：通过精心设计的提示词模板，引导 DeepSeek 将自然语言问题转换为只读 SQL，经安全校验后由 JdbcTemplate 执行并返回 JSON 结果。
  4. 智能分析报告：基于 LangChain4j AiServices + @Tool 构建 Agent 模式，支持自主规划查询步骤；同时提供混合模式（程序硬编码 + AI 生成）作为稳定方案。
  5. 前端交互：Vue 3 响应式数据绑定，Element Plus 组件库，路由守卫，Axios 拦截器，localStorage 购物车持久化。
核心代码

以下为 Text2SQL 提示词模板与前端路由守卫核心代码片段：

// Text2SQL 提示词模板 (SqlGenService.java) private static final String PROMPT = """ 你是一个SQL专家。根据以下数据库表结构： - customers(id, age, gender, location, subscription_status, purchase_frequency, previous_purchases) - products(id, item_name, category, size, color, season) - orders(id, customer_id, product_id, purchase_amount, payment_method, discount_applied, rating, review_rating, shipping_type) 将用户的自然语言查询转换为一条只读SQL语句。 要求： 1. 仅生成SELECT语句，不要有任何修改数据库的操作。 2. 不要使用分号结尾，不要加注释。 3. 查询商品信息时，必须包含 products.id 和 products.item_name。 4. 如果问题无法转换为SQL，返回"无法理解"。 用户问题：%s SQL：""";
